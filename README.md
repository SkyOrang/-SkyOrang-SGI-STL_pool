# SGI-STL_pool个人实现版本

#### 介绍
仿SGI-STL二级分配器，实现高性能内存池
封装为独立库，提供PoolMalloc/PoolFree/PoolNew/PoolDelete接口

#### 软件架构
基于C++标准库实现，没有任何第3方依赖

#### 安装教程
以VS为例：
1.  在VS项目属性页C++常规栏目附加包含库目录加入头文件路径
2.  在VS项目属性页链接器常规栏目附加包含库目录加入库文件路径
3.  在VS项目属性页链接器输入栏目附加依赖项加入要包含的库文件
